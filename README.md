# so_long

A small 2D game engine in C, built with MiniLibX: load a map from file, render sprites and a tile-based world, move a character around collecting items, and detect the win condition.

A first pass at the ideas `cub3d` later pushes much further — a render loop, keyboard input, sprite handling, and parsing a custom map format by hand, all without a game engine underneath.

**Built with:** C · MiniLibX · 2D game programming
